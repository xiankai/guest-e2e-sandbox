# Contributing

Thanks for your interest in improving this project. This is a small, throwaway
sandbox repo used for guest-instance end-to-end tests, so contributions are
mostly expected to be small and self-contained.

## Getting started

1. Fork the repo (or create a branch if you have write access).
2. Create a topic branch off `main`:

   ```sh
   git checkout -b my-change
   ```

3. Make your change, keeping commits focused and the history easy to read.

## Guidelines

- Keep changes small and tied to a single purpose.
- Match the existing style of the files you touch; don't reformat unrelated code.
- Update `README.md` when behavior or usage changes.
- Write clear commit messages in the imperative mood (e.g. "Add retry to the upload step").

## Submitting a pull request

1. Push your branch and open a pull request against `main`.
2. Describe what changed and why; link any related issue.
3. Keep the pull request open for review — it will be reviewed before merging.

## Reporting issues

Open an issue describing the problem, what you expected, and the steps to
reproduce it. Include the exact commands you ran and any relevant output.
